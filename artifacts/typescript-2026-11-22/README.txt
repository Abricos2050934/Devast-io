Devast-io-TypeScript.json — готовая локальная сборка для импорта в Resource Override.
Импортируйте JSON, оставьте включённым одно правило подмены основного JS devast.io и перезагрузите страницу.
JSON содержит полный собранный клиент; обновления с внешней ссылки в нём не используются.

Devast-io-TypeScript-source.zip — исходники только нашего мода, типы, компилятор и тесты.
JS самой игры и сторонняя dat.GUI не переводились на TypeScript.
Сначала TypeScript проверяется и преобразуется в JavaScript; браузер выполняет JavaScript.
Ничего не опубликовано и по существующей ссылке автообновления не заменено.

Сгенерированные модули совпадают побайтно с кодом до переноса.
Перенос языка сохраняет поведение и сам по себе не устраняет прежнюю проблему с киками.
Результаты и границы проверок перечислены в verification.json.
