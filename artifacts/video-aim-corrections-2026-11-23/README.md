# Исправленный локальный кандидат

Импортируйте `Devast-io-Video-Aim-Corrected.json` в Resource Override, отключите
прежнее правило подмены основного JS и перезагрузите игру. JSON содержит клиент
целиком и не загружает прежний опубликованный клиент из ветки `updates`.

Для сравнения включите `Adaptive Aim → Расчёт перехвата`,
`Video Prediction — эксперимент → Упреждение по пингу` и обычный переключатель
аима либо копья. Автобросок управляется `AutoThrow`.

В этом кандидате исправлены потеря угловой поправки перед автоброском,
неочищенная линия копья и сохранение цели/прогноза при смене режима. Краткое
описание и границы сравнения с видео: `../../docs/video-aim-corrections-2026-11-23.md`.

Основа игры — сохранённый `leZs64ZPgDsXo.js`. Подтверждены 294 сценария
собранного кандидата и браузерные fixtures Chromium/Firefox без ошибок страницы.
Живая серверная точность и совпадение с неизвестным алгоритмом автора видео
не проверены. При смене игрового протокола этот автономный снимок может
потребовать повторного переноса.

Автообновление на GitHub этим локальным исправлением не заменялось.
