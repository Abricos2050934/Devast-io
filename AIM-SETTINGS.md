# Повторная проверка настроек аимбота

Проверен именно JS из ранее выданного ZIP: SHA256
`16ad0b3c93cc7b4085cdf910036407a3ce2542bc940865d7ffb7336eda1a437d`.
Формула и рабочий JS при этой проверке не менялись.

Ядро совпадает с извлечённым ILM после удаления только неиспользуемых псевдонимов
декодера: четыре класса, 13 методов с конструкторами и цикл 50 мс. Это совпадение
ядра, а не всего старого клиента: протокол, координаты и жизненный цикл подключены
к текущей игре через адаптеры, описанные в ILM-PORT.md.

| Настройка | Наблюдаемое влияние | Условия |
| --- | --- | --- |
| AimBotEnabled | Запускает/останавливает отправку угла | Активная игровая сессия |
| AimbotKey | После переназначения новая клавиша включает аимбот, прежняя перестаёт | Вне ввода текста |
| target | Переключает игроков, гулей и общий поиск | lockId=-1 |
| mouseFovEnable | Меняет точку выбора: свой игрок или курсор | lockId=-1 |
| mouseFov | Меняет допустимую дальность от курсора | mouseFovEnable=true, lockId=-1 |
| lockId | Принудительно выбирает игрока по ID | Перекрывает категории и FOV, как в ILM |
| distanceCoefficient | Меняет точку упреждения и передаваемый угол | Нужна история движения цели |
| offsetCoefficient | Меняет точку упреждения и передаваемый угол | Нужна история движения цели |
| autoFire | Добавляет/убирает команды выстрела 4/5 | Включён аимбот и выполняется условие изменения направления ILM |
| visualizeResolving | Показывает/скрывает линию | Меняет визуализацию, не формулу |
| visualizeResolvingColor | Меняет фактический цвет линии | Визуализация включена; это подключение адаптера рендера |
| ShowRealAngles | Меняет штатное вращение своего игрока | always — всегда, withAim — только при включённом аимботе |
| bulletSpeedCoefficient | **Не влияет на расчёт** | В исходном ILM не читается алгоритмом |
| resolverType | **Не влияет на расчёт** | В исходном ILM не читается алгоритмом; отдельного переключателя в меню нет |

Нельзя одновременно сохранить исходную формулу один в один и заявить, что
последние два поля управляют ею. Для этого потребуется новая логика. Само наличие
поля, изменение значения в конфиге или сохранение значения не являются
доказательством влияния на наведение.

Проверки: 51 автоматический тест (3 Python + 48 Node), включая 12 новых проверок
изменения настроек через обработчики меню. Подтверждено совпадение поведения с
исходным ядром в 180 сценах по 6 тактов. ShowRealAngles, пакеты и подписи проверяются
в Chromium на настоящих обработчиках текущего клиента с подготовленными данными.

Это не подтверждает работу на живом сервере или отсутствие киков. Предыдущая
попытка подключения этой же сборки получила WebSocket HTTP 503. Повторная проверка
настроек не меняет данный результат проверки сервера.
