# Восстановление экрана входа — recoveryVersion 5

**Важно: `integrity-entry-v3` — архивная закреплённая сборка.** Она не является
текущим автообновлением, даже если её когда-то скачали с GitHub. Старый файл
`Devast-io-Entry-Recovery-Resource-Override.json` теперь содержит загрузчик
актуального канала `updates`, сохраняя идентификатор прежней группы импорта.

Чтобы перейти на текущую версию:

1. Отключите старые правила подмены JS devast.io, включая `integrity-entry-v3`
   и BBY, если они есть.
2. Импортируйте заново [актуальный JSON автообновления](https://github.com/Abricos2050934/Devast-io/raw/refs/heads/updates/Devast-io-GitHub-Resource-Override.json).
3. Перезагрузите игру через Ctrl+F5. В отчёте Connection должны быть
   `auditBuild: integrity-autoupdate-v1` и `integrityCompatibility: true`.

Уже импортированный в расширение файл хранится в браузере: изменение файла
в репозитории само по себе его не заменяет. `game.entry-fixed.js` и ZIP ниже
остаются исторической копией; для автообновления используйте JSON выше.

Далее приведено описание архивной версии.

Этот отдельный полный клиент сохраняет текущий аимбот, перехват оружия,
AutoBuild и предыдущую доработку трёх служебных подписей.

При зависшем запросе входа старая версия снимала флаг занятости, но не
возвращала штатный интерфейс. Новая версия отменяет просроченные callbacks,
возвращает экран с Play и позволяет повторить вход. Для зависшего начального
экрана предусмотрен отдельный таймаут 20 секунд: он действует только после
получения списка серверов и не трогает уже показанное меню, активную игру
или скрытую вкладку. Cookies, token, tokenId, userId и accountToken не очищаются.

## Установка

1. Импортировать `Devast-io-Entry-Recovery-Resource-Override.json` в Resource Override.
2. Отключить прежнюю подмену основного JS и загрузчик GitHub, чтобы работала одна версия.
3. Перезагрузить страницу. Не выполнять полный JS поверх уже запущенной игры.

Либо заменить файл в существующей подмене на `game.entry-fixed.js`.
В Connection → «Копировать отчёт входа» должны быть
`auditBuild: integrity-entry-v3` и `recoveryVersion: 5`.

Это закреплённая копия для `GqIvLJdVfXmKlyX.js`; она не обновляется автоматически.

## Проверки

- 144 Node.js и 26 Python тестов проекта прошли.
- 122 проверки переведённого установщика прошли.
- Проверка нативных функций в Chromium прошла; три перезагрузки сохранили
  данные аккаунта. Проверено обращение к публичному методу активации родного меню.
- 12 дополнительных вариантов нативных подписей прошли.

Сохранены `validation.json`, `native-browser-validation.json` и `live-check.json`.
Последний разделяет результаты реального входа и локальных проверок.

На предыдущей выданной сборке удалось войти на живой сервер Atlanta 2 и увидеть
игрового персонажа. Вход именно на этой новой сборке и повторный вход пока не
подтверждены: при последней попытке часть ресурсов и Webgames.io были недоступны
(HTTP 503); игровой WebSocket не установился. Реальный сервер в проверках не
подменялся. Отсутствие киков этим исправлением не гарантируется.

Если внешний сервис недоступен, таймаут возвращает управление к Play, но не
может восстановить сам внешний сервис. Если зависание повторилось, сохранить
«Копировать отчёт входа» до перезагрузки.
