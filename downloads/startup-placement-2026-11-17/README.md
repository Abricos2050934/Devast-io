# Эксперимент с местом установки мода

Devast-Experiment.js — полный игровой клиент с установкой мода после штатного запуска внутри основного JS. Заменяет основной игровой JS до запуска игры; не выполнять поверх уже работающего клиента. Это не userscript для Tampermonkey.

Devast-Experiment-Resource-Override.json можно импортировать в Resource Override, отключив прежнее правило. ZIP содержит тот же JSON и инструкцию.

Закреплённая версия для hym7DtRA3RCGo21.js, без автообновления. Проверены Chromium, Firefox и 116 тестов мода; отсутствие киков на живом сервере не подтверждено.

Возврат: отключить экспериментальное правило, включить прежнее, перезагрузить страницу.
