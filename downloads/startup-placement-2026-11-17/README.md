Контрольная пересборка совпала с опубликованным клиентом побайтно; после переноса сохранены все 16864 тела функций. Старый эксперимент на ILM не используется.

УСТАНОВКА АКТУАЛЬНОГО МОДА

Это эксперимент на основе опубликованного скрипта автообновления: BBY из message (27) и Adaptive Aim. Не ранний вариант с ILM.

1. Распакуйте ZIP.
2. В Resource Override нажмите Load Rules / Import.
3. Выберите Devast-AutoUpdate-Resource-Override.json.
4. Отключите прежние правила подмены основного игрового JS.
5. Перезагрузите devast.io (Ctrl+F5).

Весь скрипт встроен в JSON. Клавиши по умолчанию: Z — аим, J — вращение, M — меню, H — скрытие угла. Сохранённые пользовательские бинды могут отличаться.

Установка мода перенесена в конец штатного запуска внутри игрового JS; клиент ждёт готовности страницы. Аим, настройки и функции текущего мода сохранены.

Это закреплённый эксперимент для hym7DtRA3RCGo21.js, а не автоматическая замена опубликованного обновлятора. Отсутствие киков в матче не подтверждено.

Возврат: отключите новое правило, включите прежнее, перезагрузите страницу.


Проверены 212 тестов актуального мода, Chromium и Firefox. Source-proof.json и verification.json содержат контрольные суммы и результаты.
