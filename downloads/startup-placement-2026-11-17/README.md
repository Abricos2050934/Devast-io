Готовый архив для установки: **Devast-Resource-Override.zip**. Внутри только JSON для импорта и INSTALL.txt.

# Эксперимент для Resource Override

1. Скачайте Devast-Experiment-Resource-Override.json и импортируйте через Load Rules / Import в Resource Override.
2. Отключите прежние правила замены основного игрового JS.
3. Перезагрузите devast.io.

JSON v1 использует группу d1 и файл f1, как требует настоящий импортёр расширения. Код JS полностью встроен, скачивать его отдельно не нужно. Правило заменяет только https://devast.io/js/hym7DtRA3RCGo21.js.

Это закреплённый эксперимент без автообновления. При смене имени основного игрового JS правило перестанет применяться. Отсутствие киков на живом сервере не подтверждено.

Devast-Experiment.js — тот же полный игровой клиент отдельно. Его нужно подставлять вместо основного JS до запуска игры, а не выполнять поверх запущенного клиента.

Возврат: отключить экспериментальное правило, включить прежнее, перезагрузить страницу.
