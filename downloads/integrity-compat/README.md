# Integrity compatibility build

Отдельная пробная сборка на основе опубликованного выпуска
`79e590dc32262ca11ada8e018233b0d43c8c310c34fef150e5c3803f55ddbaae`.
Метка отчёта: `integrity-compat-v2`.

В трёх нативных вычислениях отключено влияние общего флага целостности на
служебные подписи. При выставленном флаге исходная сборка на проверенном
синтетическом входе увеличивала каждую подпись на единицу; два вычисления
меняли также служебный байт соединения. Исправленная копия должна сохранять
результат исходной сборки при нулевом флаге.

Сохранены текущие изменения переподключения (recoveryVersion 4), отрисовки,
Jitter и исходное ядро ILM. В отчёт соединения добавлены значения флага,
Jitter и AutoBuild. Основной канал `updates` этой публикацией не изменяется.

## Скачать и установить

Архив `Devast-io-Integrity-Compat.zip` содержит готовый JS, импортируемый JSON
Resource Override, этот документ и результаты проверок.

1. Импортировать `Devast-io-Integrity-Compat-Resource-Override.json`.
2. Отключить прежнюю подмену игрового JS и загрузчик обновлений GitHub.
3. Перезагрузить страницу игры. Полный JS заменяет основной игровой файл до
   запуска клиента; его не нужно выполнять поверх работающей игры.

Подмена закреплена за `GqIvLJdVfXmKlyX.js`, используемым проверенным выпуском.
Это самостоятельная копия без автообновления. Cookies очищать не требуется.
В Connection → «Копировать отчёт входа» поле `auditBuild` должно быть
`integrity-compat-v2`. При повторении сбоя сохранить отчёт до перезагрузки.

## Проверки и ограничения

`patch-report.json` содержит исходный и итоговый SHA256, точные замены,
проверку синтаксиса и границ изменения. Ядро `__createIlmAim` идентично
исходному выпуску. `native-browser-validation.json` содержит результаты
12 отдельных страниц Chromium: исходная/исправленная сборки, три нативные
функции, принудительные значения флага 0/1. Используются синтетические данные,
все внешние сетевые запросы блокируются.

Проверка доказывает условное влияние флага и исправление именно этого
вычисления. Она не воспроизводит пользовательский кик и не подтверждает,
что флаг выставлялся в браузере пользователя. Отсутствие киков на живом сервере
не проверено; серверные ограничения и другие причины отключений не исключены.

## Воспроизведение

Установить зависимости проекта (`npm ci --ignore-scripts`) и Chromium.
Скачать исходный JS выпуска, чей SHA256 указан в `source-current.json`.

```sh
node downloads/integrity-compat/package.cjs original.js downloads/integrity-compat/source-current.json downloads/integrity-compat
node downloads/integrity-compat/test-native.cjs original.js
```

Пакетировщик проверяет SHA256 до изменений и останавливается, если ожидаемые
три предиката изменились. Это не универсальный патч для произвольной версии игры.
