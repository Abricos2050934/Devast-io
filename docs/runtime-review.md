# Проверка замечаний к моду

Проверены текущие исходники, генератор и установленный адаптер. Эта проверка
описывает корректность клиента. Срабатывание серверных проверок по этим данным
не установлено. Изменения проверок целостности и средств обнаружения в эту
работу не входят.

| № | Результат проверки и действие |
| --- | --- |
| 1 | Подтверждено. AutoThrow получил `spearAutoThrow`. Старое сохранение общего флага переносится один раз, новые значения сохраняются независимо. |
| 2 | Подтверждено. Неизвестный, отсутствующий и неактивный ID безопасно считаются отсутствием живого игрока. Проверены `isDead()` и `afterFire()`. |
| 3 | Подтверждено. `reset()` имеет конечные значения по умолчанию; массовый сброс передаёт четыре координаты явно. |
| 4 | Подтверждено. `set()` сохраняет флаг выхода за дальность; отрисовщик снижает прозрачность такой линии. Обычное обновление сбрасывает флаг. |
| 5 | Подтверждено. Удалены две недостижимые повторные конвертации `null` в угол. |
| 6 | Подтверждено. Коэффициент Strafe теперь меняет продвижение по шаблону. Частота существующего таймера сохраняется, значение 100 соответствует прежнему шаблону. |
| 7 | Хост уже устраняет конфликт биндов при загрузке и меняет местами конфликтующие назначения. Проверено назначение клавиши меню другому действию. |
| 8 | Подтверждено. Неиспользуемый `ModMenuKeyCode` удалён из действующих настроек и назначения клавиш. |
| 9 | Подтверждено частично. Запись уже проходила через `setSetting()` благодаря Proxy. Повторный захват и Escape действительно требовали исправления. Теперь действует один обработчик, есть отмена, проверка значения и повтор после недопустимой клавиши. |
| 10 | Пара команд раз в 50 мс присутствует. Это частота запросов, а не доказанная скорость принятых сервером ударов. Авторитетная перезарядка и причина кика неизвестны; произвольный порог не вводился. |
| 11 | Подтверждён лишний пересчёт Adaptive Aim на каждом пакете. Изменения координат сохраняются сразу, выбор цели выполняется существующим циклом; непосредственно перед выстрелом угол пересчитывается. Проверена пачка из 300 обновлений. |
| 12 | Подтверждена возможность перехвата вторым касанием. Палец прицела закрепляется до touchend/touchcancel; касания DOM-кнопок игнорируются. Привязка к мобильному джойстику требует проверки на реальном устройстве. |
| 13 | Ветка не представлена в меню, но вызывается напрямую через API и покрыта регрессией. Она сохранена для совместимости. |
| 14 | Подтверждено. Повторный расчёт мировых координат курсора удалён. |
| 15 | Хост действительно владеет сохранениями и загружает их до создания ядра. Неиспользуемая импортированная миграция и её имитация localStorage удалены. Сохранение вызывает хост напрямую. |
| 16 | Подтверждено. Удалён неиспользуемый расчёт `ang`; действующая геометрия копья сохранена. |
| 17 | Список неточен. `PlayerId` используется копированием ника, `Token` — ручным вводом подключения и затем очищается. Эти поля сохранены; данные аккаунта не удалялись. |
| 18 | Точные строки применяются к проверенному снимку на этапе сборки. Auto-port сначала сопоставляет нативные функции по AST и создаёт новые anchors. Старые функции-помощники не выполняются при каждом игровом кадре. Неизвестное изменение останавливает новую публикацию; предыдущая версия остаётся доступной. |
| 19 | Ненадёжный поиск произвольного числового поля удалён. Помощник сравнивает явно переданный ID либо поле `id`. |

Целевые проверки находятся в `tests/aim-review.test.cjs`. Отдельная регрессия
сверяет прежние расчёты и порядок команд на одинаковых входных данных;
разделённые флаги и новые значения скрытых линий учитываются явно. Все поправки
вносятся генератором, поэтому повторная сборка сохраняет исправления.
