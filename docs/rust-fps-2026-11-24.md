# Оптимизация нагрузки Rust-мода

Воспроизведена высокая нагрузка при поиске цели и отрисовке. Исходный динамический
Rust-перенос передавал даже чтение переменной через универсальный мост, повторно
создавал строки, массивы аргументов и области переменных. Поиск цели усиливал
расходы повторными чтениями метаданных и вычислениями в callback для каждого игрока.

Изменения:

- Частые операции используют прямые импорты Wasm; вызовы с 0–4 аргументами
  передают значения за один переход через мост.
- Неизменяемые строковые литералы и небольшие целые числа переиспользуются.
  Динамические имена игроков, пакеты и объекты в кеш не попадают; signed zero сохранён.
- Проверка цели, оценка кандидата и метаданные выполняются без временных JS-scopes.
  Формула расстояния по-прежнему floor(sqrt(dx²+dy²)); сохранены порядок при равенстве,
  дальность, приоритет предыдущей цели, удержание и клановые ограничения.
- Проекция игрока и цвет хитбокса не вычисляются, когда их результат не рисуется.
  Имена, хитбоксы и карма остаются доступны и проверены сравнением с JS-источником.
- Rust release компилируется с opt-level=3.
- Отдельно устранены холодные всплески подбора стрейфа: числовой перебор частоты
  и коэффициентов выполняется в src/motion.rs без временных JS-объектов.
  Исходные частоты, ограничения, формулы и функции смещения сохранены.
  На 96 детерминированных историях модели и координаты перехвата совпали с JS.

Все 406 исходных функций и их идентификаторы сохранены. generated.rs содержит
ручные оптимизации f_27, f_29, f_193, f_258 и f_298: не перегенерировать его без
сохранения этих участков. Обычные build_rust/build_rust_client компилируют Rust
напрямую и не запускают мигратор.
Также сохранять вызовы числовых ядер из f_133/f_139.

Синтетический CPU-замер в Node: 5 прогревочных вызовов, 25 измерений на операцию,
30 и 90 игроков, включённый аим и нативные подписи игроков. Для 90 игроков медиана
поиска цели уменьшилась примерно с 32 до 5 мс, отрисовки слоя мода — с 16 до 5 мс.
Замер проверяет valid_prediction, чтобы устаревшие координаты не позволяли
пропустить расчёт упреждения. Отдельный холодный расчёт моделей (8 новых историй)
сократился с 68 до 4,4 мс для стрейфа и с 94 до 4,4 мс для стрейфа с дрейфом.
Это время отдельных операций, не FPS игры; серверная физика, GPU и устройство
пользователя этим замером не охвачены. Полные результаты сохранены с выпуском.

Команда для повторения: `node tools/benchmark_rust_frame.cjs report.json`.
Для другого собранного Wasm установить DEVAST_RUST_MOD в каталог с bridge.js,
function-manifest.json и pkg/. Предыдущий baseline должен иметь собственный мост,
соответствующий его Wasm.

Выпуск: artifacts/rust-mod-fps-2026-11-24/. Основной импорт —
Devast-io-Rust-Resource-Override-Fixed.json. Перед импортом отключить старое правило
подмены JS и перезагрузить игру. Проверки и контрольные суммы — в verification.json.
Живой сервер в проверках не использовался.
