## Сборка и проверка

Нужны Node.js 24, Python 3.12+, Chromium и Firefox для Playwright.

```sh
npm ci --ignore-scripts
npm run typecheck
npm run build:mod
npm run check:generated
npm run build
npm test
```

Экспериментальная воспроизводимая сборка:

```sh
npm run build:video-aim
python3 tools/package_video_aim.py
```

Проверка и перенос на официальный JS, который сейчас отдаёт сайт:

```sh
npm run update:once
```

`update:once` должен завершить статические проверки, тесты кандидата и проверки
Chromium/Firefox. Публикация выполняется только после успешного кандидата:

```sh
python3 tools/publish_update.py
```

Push в `main` также запускает `.github/workflows/auto-update.yml`; workflow
публикует прошедший все проверки клиент в ветку `updates`.

## Использование Resource Override

Файл `resource-override/Devast-io-GitHub-Resource-Override.json` подменяет основной
`/js/*.js` загрузчиком. Загрузчик синхронно получает:

```text
https://raw.githubusercontent.com/Abricos2050934/Devast-io/updates/client.js
```

После импорта JSON нужно отключить старые правила подмены и перезагрузить страницу.
Повторный импорт для каждого выпуска не требуется: постоянная ссылка остаётся той
же. Полный клиент нельзя запускать вторым экземпляром поверх уже загруженной игры.

## Экспериментальный режим прогноза

Режим включается в
`Adaptive Aim → Video Prediction — эксперимент → Упреждение по пингу`.
Также должны быть включены `Расчёт перехвата` и соответствующий обычный
переключатель аима или копья. Панель слева управляется отдельным переключателем.

Параметры скриншота и поведение записи не раскрывают исходную формулу автора.
Текущая реализация — собственная модель. Она использует средний подтверждённый RTT,
а до появления таких замеров показывает явно заданное значение. Автоматическое
измерение RTT через неподтверждённые пакеты не добавлялось.

Синтетическая проверка подтверждает расчёт, порядок «угол перед выстрелом», работу
панели и отсутствие дополнительных сетевых пакетов. Она не является измерением
процента попаданий на живом сервере.

## Результаты и границы проверки

- Строгая компиляция TypeScript и тесты исходного пакета экспериментального режима
  прошли.
- Кандидат прошёл 291 сценарий и браузерные проверки Chromium и Firefox.
- Панель проверена в браузерном fixture с искусственными RTT-замерами.
- В независимой симуляции режим с известной задержкой улучшал результат по сравнению
  с вариантом без компенсации; преимущества перед уже правильно откалиброванной
  прежней моделью не установлено.
- Живая минутная сессия без отключения не подтверждена. В прежних прогонах и
  модифицированный, и штатный клиент получали серверный пакет смерти `opcode 27`;
  локальный вызов `WebSocket.close()` перед ним не обнаружен. Причина серверного
  решения из клиентских данных не установлена.
- Браузерные fixtures подтверждают совместимость клиентских функций, но не обещают
  отсутствие кика или точность на реальном сервере.

## Правила дальнейших изменений

1. Менять TypeScript-исходники, затем выполнять `npm run build:mod`.
2. Не редактировать сгенерированные `mod/*.js` и
   `resource-override/loader.js` отдельно от `.ts`.
3. Не заменять текущий мод старым готовым JS и не применять прежние исправления
   повторно.
4. При новой версии игры запускать перенос и оба браузера; неизвестный нативный
   контракт должен остановить публикацию.
5. Не включать в коммиты `.updater/`, `.private-updates/`, cookies, ключи,
   персональные токены и зависимости `node_modules/`.
6. Не описывать локальный fixture как живой серверный тест.
