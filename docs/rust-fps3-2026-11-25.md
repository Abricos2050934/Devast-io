# Проверка совместной нагрузки функций

Выпуск: `artifacts/rust-mod-fps3-2026-11-25/`. Игра и 406 исходных функций
сохранены. Оптимизированы проверка кланов, обработка ников, быстрый лут и
предикаты медленного лута. Список игроков теперь сравнивает снимок своих входных
данных и обновляет DOM при изменениях. Имена, состав, кланы и цвета обновляются
сразу; закрытие и повторное открытие проверены отдельным тестом. Частота и
лимиты отправки запросов лута сохранены.

Проверки: 301/301 сценарий для канонического Wasm, 301/301 для нативного,
11 проверок моста, кеша и соответствия расчётов, 3 проверки настоящего импортёра
Resource Override. Chromium и Firefox проходят проверку нативного клиента без
ошибок страницы. Архив исходников проходит чистую установку зависимостей и smoke.

Нагрузочный инструмент: `DEVAST_STRESS=1 node tools/benchmark_rust_workload.cjs`.
12 сцен, по 180 кадров: 30/90 игроков, 600/2000 строений и 1024 предмета.
Включены хитбоксы, список игроков, карма, автоматика строительства, контейнера,
чата, вращения и движения. Fast/slow loot и режимы adaptive/video/spear/legacy
проверяются раздельно из-за взаимоисключения настроек. Исполняются таймеры с
удалением отработавших однократных callbacks. Массивы записи canvas-вызовов
тестового окружения очищаются после кадра. В adaptive/video получено по 177
кадров с валидным прогнозом; legacy/spear не используют этот флаг прогноза.

Итоговый CPU replay новой сборки, миллисекунды:

| Сцена | Медиана кадра | p95 | Максимум |
| --- | ---: | ---: | ---: |
| 30 игроков, быстрый лут | 9.8 | 17.8 | 24.9 |
| 30 игроков, медленный лут | 9.1 | 25.7 | 35.4 |
| 90 игроков, быстрый лут | 18.4 | 34.1 | 38.9 |
| 90 игроков, медленный лут | 19.2 | 43.6 | 51.0 |
| 90 игроков, video aim | 17.9 | 31.6 | 34.6 |
| 90 игроков, legacy aim | 17.3 | 134.2 | 136.2 |

Проверка **не подтверждает отсутствие лагов**. Legacy продолжает вызывать
пересчёт на каждом пакете позиции и даёт большие пики в массовой сцене.
Его временная семантика сохранена; ускорения не заменяют его расчёт другим
режимом и не выключают настройки. В остальных плотных сценах также бывают
кадры дольше бюджета 16.7 мс. Это стоимость мода на синтетическом CPU стенде;
в неё не включены полная физика игры, GPU и особенности конкретного устройства.
Обработчики mines/wires проверены браузерными fixtures, но их реальная GPU
нагрузка здесь не измеряется. Вход на живой сервер и длительное измерение FPS
на устройстве пользователя не выполнялись. Ничего не опубликовано.
