# Текущий аимбот: оригинальный ILM 1.0

Space — включение аимбота, H — меню. Клавиша переназначается в Keyboard.
Исходные пять контролов находятся в Aim Bot, остальные переключатели — ILM controls.
Один такт50мс, исходные четыре класса и вся история/формула/автоогонь восстановлены.
Untitled, Message15 и Curved удалены из активного клиента.

Параметры стартуют с родных значений ILM: distance300, offset0.1, bulletSpeed4,
mouseFov12345. Как в исходнике, bulletSpeedCoefficient не влияет на формулу.
Параметры других движков автоматически не подставляются. Новый ключ —
DevastILMOriginal:aim:v1. Учётная запись, cookies и настройки других функций сохранены.
