## Сборка и проверки

Нужны Node.js, Rust с целью wasm32-unknown-unknown и wasm-bindgen-cli 0.2.105.
Версии зависимостей закреплены в package-lock.json и rust-mod/Cargo.lock.

```sh
npm ci
rustup target add wasm32-unknown-unknown
cargo install wasm-bindgen-cli --version 0.2.105 --locked
npm run build:rust
npm run build:rust-client
npm run test:rust
npm test
```

При проверке конкретной перенесённой основы использовать её каталог кандидата:

```sh
DEVAST_TEST_CANDIDATE=/absolute/path/to/candidate node tools/test_rust.cjs rust-mod/native
DEVAST_RUST_RUNTIME=rust-mod/native/owned-runtime.js DEVAST_BROWSER=chromium node tools/validate_update.cjs /absolute/path/to/candidate
DEVAST_RUST_RUNTIME=rust-mod/native/owned-runtime.js DEVAST_BROWSER=firefox node tools/validate_update.cjs /absolute/path/to/candidate
```

`validate_update.cjs` записывает validation.json в каталог кандидата: для Rust
использовать отдельную копию каталога и сохранять отчёты каждого браузера отдельно.

Сборка Rust читает `.rs`, bridge.js и native-base; TypeScript для неё не нужен.
Не запускать `tools/generate_rust.cjs` поверх ручных Rust-изменений: это инструмент
повторения первоначальной миграции, он перезаписывает generated.rs.

Текущий источник — `https://devast.io/js/SoU74f1CSGBLrnN70LACrWeKIQ.js`.
SHA256 исходника: `f486858e2155cc0cca5f95fa66e0ecd6f7c8a670cc62b655e8dac0bf06724930`.
Снимок закреплён в `baselines/latest.json`.
Rust-клиент: `0c1e9ca6c9f0102fffac64620de166b7e31e2f775ff1ded78ea191026f35eb3c`.

Обычная команда `npm run build` собирает JavaScript-вариант. Штатный обновлятор
также пока обновляет JavaScript-вариант, Rust-выпуск собирается отдельно.
Порядок перехода на следующую основу:

1. `npm run update:source` — определить текущий источник.
2. `npm run update:once` — выполнить локальный перенос и проверки нового кандидата.
3. Закрепить проверенный исходник и его SHA в baselines/latest.json, выполнить npm run build.
4. `node tools/build_rust_client.cjs --pin-native` — явно заменить Rust-основу.
5. Повторить 301 Rust-сценарий и оба браузера на новом кандидате.
6. `node tools/package_rust.cjs` — пересобрать автономный архив и проверить его отдельно.

Сборщик выпуска сейчас пишет в `artifacts/rust-mod-2026-11-24/`; при следующем
выпуске согласованно изменить путь в build_rust_client.cjs и package_rust.cjs.
Сохранять предыдущие проверенные выпуски. Не менять `updates` и публичную ссылку
автообновления без отдельного запроса на публикацию клиента.
