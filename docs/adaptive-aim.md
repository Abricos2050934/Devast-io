# Adaptive Aim — 13 ноября 2026

Новый режим включён по умолчанию: `Adaptive Aim → Расчёт перехвата`.
Он подключён к текущему аимботу BBY из message (27), его выбору целей,
кланам, клавишам, ручному/автоматическому огню и Jitter. Исходные блоки BBY
сохранены; выключение нового режима возвращает исходный расчёт.

## Что изменено

Скорость берётся из штатного описания выбранного оружия, а дальность — из его
`path`. Поэтому первое наведение не ждёт пристрелки. Собственные снаряды уточняют
скорость: используется среднее до девяти разных пуль отдельно для каждого оружия,
с удалением крайних значений при достаточной выборке. Повторный пакет одной пули
не считается новым измерением. Чужие пули не обучают наше оружие. Перенос проверяет
контракт штатных конструкторов `(state >> 8) / 100`; браузер сравнивает полученную
скорость с настоящим нативным объектом снаряда.

Позиции берутся из серверных координат пакета, отдельно от его конечной точки
интерполяции. Скорости стрелка и цели оцениваются по временным меткам последних
пакетов в мировых единицах в секунду. Движение стрелка учитывается до момента
запуска пули. Скорость ходьбы не прибавляется к пуле после выстрела.

Для прямолинейного движения решается уравнение перехвата. Для устойчивого движения
по окружности проверяются восемь наблюдений, ошибка окружности и согласованность
угловой скорости; нужны два согласованных приближения. При остановке, резком
развороте, телепортации, смене поколения или пропаже истории прежнее движение
не продолжается вслепую. Устаревшая позиция старше 350 мс не допускается к огню.
Учитывается дальность оружия; недостижимая цель освобождает управление направлением.

Перед ручным выстрелом и автоматической атакой пересчитывается направление.
Оно передаётся до команды атаки. Jitter уступает выстрелу, проверка очереди сокета
сохранена. Обычное адаптивное наведение на удерживаемую цель ограничено 20
направлениями в секунду; новая цель и выравнивание перед выстрелом имеют
немедленный приоритет. Дополнительный таймер
не создаётся — используется существующий цикл 50 мс.

## Настройки

| Пункт в Adaptive Aim | Действие |
| --- | --- |
| Расчёт перехвата | Новый расчёт или исходный BBY |
| Скорость из игры и пуль | Штатная скорость, затем уточнение по собственным пулям |
| Резервная скорость, ед/мс | Используется без штатных данных либо при отключённой автоматике; 1,5 по умолчанию |
| Компенсация задержки, мс | Дополнительное время прогноза стрелка и цели; 0 по умолчанию, автоматическое измерение RTT не заявляется |

Выбор категории, FOV, LockId, кланы, отображение линии и клавиши остаются общими.
DistanceCoefficient, OffsetCoefficient, LeadCap и AimSmooth относятся к исходному
расчёту BBY при выключенном «Расчёте перехвата». Их прежние значения сохранены.
Сглаживание направления и фиксированное обрезание упреждения не применяются поверх
физической точки попадания. Копьё сохраняет отдельную исходную геометрию BBY.
Данные входа, cookies и токены новый режим не изменяет.

## Проверка и ограничения

`node tools/benchmark_ballistics.cjs` воспроизводит независимое движение пули
с шагом 1 мс, квантованием позиций/углов и штатной скоростью AK47 1,4 ед/мс.
Сравниваются исходные настройки BBY, ранее выбранный профиль 60/1/200/1 и новый
режим на одинаковых 108 сценариях. На 81 сценарии с предсказуемым движением:

| Режим | Среднее отклонение | В пределах 20 единиц |
| --- | ---: | ---: |
| BBY по умолчанию | 21,62 | 40/81 |
| Подобранный профиль BBY | 9,48 | 74/81 |
| Adaptive Aim | 2,13 | 81/81 |

Отдельные 27 сценариев содержат разворот после запуска пули: его ещё нет в
полученных данных, и новый режим также промахивается. По всем 108 сценариям
среднее отклонение — 32,11 против 38,84 у подобранного профиля и 40,73 у исходного.
Это симуляция, а не измеренный процент попаданий на живом сервере.

Не гарантируются будущие движения цели, неизвестная задержка, разброс, смещение
ствола и столкновения со стенами. Серверных подтверждений попадания клиентский
прогноз не подменяет. Актуальная сборка дополнительно проходит Chromium, Firefox,
тесты переведённого адаптера и полный пакет регрессии через штатный обновлятор.

Исходник модели: `mod/ballistic-model.js`; генерация в `mod/ilm-aim.js` проверяется
на точное совпадение. Контракт автообновления включает оба файла. Полный численный
отчёт: `verification/ballistics-2026-11-13/accuracy.json`.
