# Исправление подготовки автообновления

Публичный клиент отставал от текущего JS игры. Последний запуск публикации
после сохранения исходников был явно отменён. Новый запуск 45350898630 выявил
отдельную инфраструктурную причину: установка зависимостей Playwright превысила
таймаут 5 минут до начала сборки. Региональное зеркало
us-east-2.ec2.archive.ubuntu.com медленно отдавало пакеты шрифтов и видеокодеков.

В auto-update.yml список зеркал временной GitHub-машины теперь направляется
на официальный HTTPS-архив Ubuntu. Проверка подписей APT сохраняется.
На установку зависимостей отведено 10 минут, на полный запуск — 30 минут.
Повторные попытки установки, оба браузера, тесты кандидата, регрессионные тесты,
проверка актуальности игрового источника и защита публикации сохранены.

Workflow запускается по изменениям main, вручную и по расписанию
`7,22,37,52 * * * *`. Расписание GitHub может задерживаться; ручной запуск:

```sh
gh workflow run auto-update.yml --repo Abricos2050934/Devast-io --ref main
```

Результат публикации проверять по updates/current.json и контрольной сумме
updates/client.js. Resource Override загружает client.js с параметром времени,
чтобы браузер не использовал прежнюю копию. Публичный обновлятор собирает
JavaScript-вариант; автономный Rust/Wasm-выпуск хранится отдельно в artifacts.
