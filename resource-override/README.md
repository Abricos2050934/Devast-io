# Resource Override: загрузка нашего клиента по ссылке

Импортируйте Devast-io-GitHub-Resource-Override.json в то же расширение, где
использовался BBY-GitHub-Resource-Override.json. Формат v1 и правило fileOverride
сохранены: подмена https://devast.io/js/*.js выполняет небольшой загрузчик.

1. Скачайте JSON и импортируйте его через Import в расширении.
2. Отключите прежние правила подмены основного JS devast.io, включая BBY-правило.
3. Перезагрузите игру; при первом применении можно использовать Ctrl+F5.

Загрузчик синхронно получает готовый клиент:
https://raw.githubusercontent.com/Abricos2050934/Devast-io/updates/game.modded.js

После получения он выполняет полный клиент вместо оригинального игрового скрипта.
Параметр t=Date.now() обновляется при загрузке страницы. Двойное выполнение клиента
блокируется; ошибки сети и неверный файл выводятся в консоль браузера.
JSON не содержит аккаунтов, cookies и токенов.

Бот проверяет сайт и публикует прошедшие тесты сборки в updates каждые 15 минут
(возможны задержки GitHub Actions). Новая опубликованная версия будет загружена
при следующей перезагрузке страницы; переимпорт JSON не требуется. Уже запущенный
матч не перезапускается автоматически.

Сам JSON включается в публикуемый набор и ZIP вместе с JS:
https://github.com/Abricos2050934/Devast-io/raw/refs/heads/updates/Devast-io-GitHub-Resource-Override.json

Исходник загрузчика — loader.js. После его изменения JSON пересобирается командой
python3 tools/make_resource_override.py; тест проверяет совпадение файлов.
