# Где разместить магазин

GitHub хранит исходники и запускает проверки проекта. GitHub Pages публикует
статические HTML/CSS/JS и не исполняет Python-процесс магазина, который принимает
`POST /devast` и хранит SQLite. CI в этом репозитории проверяет код и завершается;
он не выдаётся за постоянно работающий игровой вебхук.

Официальная инструкция Devast.io описывает подключение `!start-webhook=IP`
к внешнему HTTP-серверу на порту **8000**. Прямой подходящий вариант — Linux VPS
с публичным IPv4, открытым TCP 8000 и постоянным диском. Наличие обычного
HTTPS-адреса приложения на 443 само по себе не подтверждает совместимость.

## Подходящие провайдеры

| Вариант | Почему подходит | Что требуется |
| --- | --- | --- |
| [Oracle Cloud Always Free](https://www.oracle.com/cloud/free/) | Виртуальная машина и постоянный диск; можно принимать запросы на своём порту | Собственный аккаунт Oracle и доступная Always Free VM в регионе; регистрация/проверки выполняются владельцем |
| [Hetzner Cloud](https://www.hetzner.com/cloud/) | VPS с постоянным диском и настраиваемой сетью | Аккаунт Hetzner и оплаченный сервер; стоимость/IPv4/налоги нужно проверить при создании |

Для этого небольшого сервиса достаточно Ubuntu 24.04, 1 vCPU и 1–2 ГБ RAM.
Выбирай именно ресурс, помеченный Always Free, если нужен бесплатный вариант;
пробные кредиты на произвольную VM не означают бесплатную постоянную работу.

Проверено по официальным страницам 11.11.2026. Наличие и условия бесплатных
ресурсов зависят от аккаунта и региона. Никакой платный ресурс этим PR не создан.

## Подготовленная установка из GitHub

После появления хоста и доступа к нему:

```bash
git clone --branch codex/server67-shop-hosting https://github.com/Abricos2050934/Devast-io.git
cd Devast-io/server-shop
sudo bash deploy/install-vps.sh --game-source ИСХОДЯЩИЙ_IP_ИГРОВОГО_СЕРВЕРА
```

Установщик создаёт отдельного системного пользователя, устанавливает systemd
службу и сохраняет деньги в `/var/lib/devast-shop/shop.sqlite3`. Существующая
база и пользовательские цены при повторном запуске не заменяются.
Разреши TCP 8000 только от игровых IP в фаерволе провайдера. Затем включи
`!start-webhook=ПУБЛИЧНЫЙ_IP_VPS` через админ-вход в сервер 67.

Сначала требуется определить реальные исходящие IP игрового вебхука. Внешний
адрес браузера или адрес CDN главной страницы игры для этого не подходит.
Детали, команды игроков и проверка первой сделки описаны в [README](README-ru.md).

Для автоматической установки в этой сессии подготовлен публичный SSH-ключ,
который можно добавить в аккаунт облака при создании VPS. Приватный ключ
не находится в репозитории. Пароль администратора игры также не публикуется.
