# TypeScript опубликованного мода

Это перенос **нашего мода из `updates/client.js`**, скачанного по новой ссылке
автообновления. Исходный файл зафиксирован SHA-256 в `source.json`.
Основной JavaScript игры и сторонняя dat.GUI не переведены на TypeScript.

- `core.ts` — ядро, прицеливание, настройки и вспомогательные функции: 138 функций.
- `host.ts` — меню, управление, визуальные функции и соединение: 208 функций.
- `bootstrap.ts` — подключение мода к игре: 11 функций.
- `../resource-override/loader.ts` — загрузчик по существующей новой ссылке.
- `compatibility.d.ts` — объявления динамических объектов и внешних интерфейсов.

Все объявления, выражения, значения, строки патчей и тела функций сохранены.
Тип `PublishedDynamic` обозначает динамические значения исходного JavaScript
через `any`: это перенос без изменения поведения, а не доказательство полной
безопасности типов. Проверка `strict` включена; подавлений ошибок нет.

```sh
npm ci --ignore-scripts
npm run check:published-mod
npm run build:published-mod
```

Сборщик проверяет типы, сопоставляет результат с официальным компилятором
TypeScript по AST и сохраняет исходную разметку JavaScript. Затем он проверяет
побайтное совпадение каждого фрагмента и полного клиента с опубликованным файлом.
Отдельно проверяется загрузчик. Ошибка проверки останавливает сборку до записи
результатов. `reference-client.js.gz` — неизменяемый снимок исходного JavaScript
для проверки и сборки; его нативная часть не редактируется.

Результаты находятся в `artifacts/published-typescript-2026-11-22/`:
`client.js`, `Devast-io-TypeScript.json` и `verification.json`.
Браузер исполняет собранный JavaScript.

Это отдельный перенос опубликованной версии. Более новые локальные изменения
в `mod/` сохранены. Публикация, смена ссылки и проверка живого игрового сервера
в эту сборку не входят. Сборщик намеренно отклоняет изменения поведения относительно
зафиксированной версии: такой перенос должен сохранять все функции исходника.
