# Исправление повторного входа без сброса cookies

Изменения в этой версии:

- Инициализатор игры больше не создаёт новый token при несовпадении serverVersion.
  Существующая связка token/tokenId/userId сохраняется; token создаётся только
  если отсутствует. Штатные ответы сервера продолжают обрабатываться игрой.
- Настройки перенесены в DevastILM:settings:v3 с чтением старого BestModMenuConfig
  и фильтра предметов. Ключи аккаунта и cookies при миграции не изменяются.

- Отдельно обработан отказ восстановления завершённой сессии (нативное состояние 256).
  После него разрешена одна обычная попытка входа с теми же сохранёнными данными.
- Сбрасывается только временное состояние сетевого подключения, влияющее на флаг
  восстановления. Cookies, token, tokenId, userId и настройки модификации не удаляются.
- Повторные нажатия Play до завершения начального запроса не создают параллельные
  подключения. Устаревший ответ предыдущей попытки не запускает новое соединение.
- Изменённый выбор сервера сохраняется; отложенный повтор старого подключения отменяется.
- Проверка повреждённого сохранённого userId исправлена: сравнение NaN === id никогда
  не срабатывало. Теперь применяется предусмотренное оригиналом конечное значение
  по умолчанию в пакете входа, без удаления или перезаписи хранилища аккаунта.
- Закрытие ещё не созданного WebSocket больше не вызывает обращение к undefined.
- Отказы по версии/доступу не запускают цикл сброса идентичности.

Проверки: 95 автоматических тестов, синтаксис и AST. Три последовательные
перезагрузки Chromium с прежней версией serverVersion сохранили token, tokenId,
userId, cookies, параметры наведения и фильтр предметов. В Chromium вызван штатный обработчик отказа
восстановления на подготовленных нативных объектах: выполнена одна обычная попытка,
флаг пакета входа равен 0, cookies и данные аккаунта/настройки сохранились.
Отдельно проверен штатный пакет: при восстановлении флаг равен 1, при обычном входе 0;
остальные поля идентичности одинаковы. На испорченном сохранённом ID проверен fallback.

На Frankfurt 2 проверены обе текущие сборки. Базовая сборка отработала 60 секунд,
после чего прошла переподключение и вход после перезагрузки. Сборка автообновления
проверена отдельно, с включённым аимботом при переподключении и после перезагрузки.
Во всех подтверждённых повторных входах сохранились token, tokenId, userId и cookies.
Ошибок мода в этих прогонах нет. Это результаты конкретных прогонов, а не гарантия
доступности каждого сервера.

Предыдущая проверка с ограничением HTTP 503 сохранена отдельно:
[ранний отчёт Chromium](verification/browser-2026-11-02.json).

Установка: замените старый game.modded.js новым файлом в подмене основного скрипта,
затем перезагрузите страницу. Для применения исправления не требуется очищать cookies
или localStorage. Не выполняйте полный файл поверх уже работающего игрового клиента.
