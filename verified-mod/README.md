# Проверенная TypeScript-сборка мода

Исходники нашего мода находятся в `mod/*.ts`, загрузчик — в
`resource-override/loader.ts`, общие контракты — в `mod/contracts.d.ts`.
Проверка TypeScript 5.9.3 работает с `strict: true` и без подавлений ошибок.
Тип `NativeValue` (`any`) применяется на динамической границе с игрой.
Основной код игры и сторонняя dat.GUI остаются JavaScript.

Первая переданная версия была точным переносом опубликованного файла
`updates/client.js`. Более широкая проверка выявила в ней 49 неуспешных
проверок из 270. Эта сборка использует исправленные TypeScript-модули:
отдельный AutoThrow, проверки неизвестного ID и координат линий, исправления
назначения клавиш и касаний, интервалов автоматизации, управления движением,
повторных и запоздалых обработчиков входа, ожидания открытия сокета и диагностики.
Сохранены функции меню, отображения, прицеливания, автоматизации и соединения.

```sh
npm ci --ignore-scripts
npm run typecheck
npm run build:verified-mod
npm test
```

В самостоятельном архиве `npm run build` также вызывает сборку проверенного
клиента. Она работает без загрузки нового JS игры: базовый JavaScript зафиксирован
в `verified-mod/native.js.gz`, его SHA-256 проверяется. Исходные `.js` мода
генерируются из `.ts`, поэтому редактировать их отдельно нельзя.

Результаты появляются в `artifacts/verified-typescript-2026-11-22/`:
`client.js`, `Devast-io-TypeScript-Verified.json`, `build-verification.json`.
Сборка сверяет результат с хешем клиента, прошедшего функциональные и браузерные
проверки. После новых изменений исходников этот хеш требует повторной проверки.
В самостоятельном архиве `npm test` запускает проверки компилятора и контрактов;
отчёты полного функционального прогона приложены отдельно.

Для собранного клиента прошли 270 функциональных тестов и локальные проверки
нативных сценариев в Chromium и Firefox. Отчёты связаны с хешем клиента
в `verification.json`. Браузерные сценарии используют тестовые данные и не
подтверждают длительную сессию на обычном игровом сервере. Проверка переноса
TypeScript не является доказательством отсутствия всех возможных ошибок.

Публикация и ссылка автообновления не изменены.
