# Откат

Исходное вложение неизменно хранится в `recovery/game.modded.ilm.js.gz`.
Оригинал текущей игры — `baselines/current.js.gz`. Это разные файлы.

Чтобы получить исходный старый мод в отдельном файле без перезаписи новой сборки:

```sh
python3 - <<'PYCODE'
from tools.recover_client import ROOT, original
(ROOT / 'build').mkdir(exist_ok=True)
(ROOT / 'build/game.uploaded.js').write_bytes(original())
PYCODE
```

Инструмент проверит SHA-256 архива до сохранения. Старый файл совместим со своей
исторической основой, а не подтверждённо с текущей игрой.

Для сборки текущего переноса: `npm run build`. До редактирования мода сохраняйте
свои изменения; предыдущая Git-история, ветки и теги в предоставленном JS отсутствуют.
