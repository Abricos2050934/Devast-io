# Исходники мода на TypeScript

Редактируемый код мода находится в `responsive.ts`, `ilm-aim.ts`,
`ballistic-model.ts`, `bootstrap.ts` и `../resource-override/loader.ts`.
Общие типы настроек, команд, целей, предсказаний и соединения описаны в
`contracts.d.ts`. Динамические поля нативной игры и сторонней dat.GUI остаются
явно обозначенной границей совместимости `NativeValue`.

Файлы `.js` рядом с исходниками генерируются для существующего сборщика,
тестов и автообновления. Их нельзя редактировать независимо от `.ts`.
Нативные снимки игры в `baselines/`, правила переноса в `patches/` и библиотека
в `vendor/` остаются на JavaScript.

```sh
npm ci --ignore-scripts
npm run typecheck
npm run build:mod
npm run build
npm test
```

`typecheck` проверяет все пять фрагментов с `strict: true` и общими контрактами.
`build:mod` обновляет совместимые `.js` и встроенный загрузчик Resource Override.
`build` затем собирает полный клиент с нативным снимком игры.
`check:generated` проверяет, что `.js` соответствуют текущим `.ts`.

Сборка использует только стираемые конструкции TypeScript. Разметка исходного
JavaScript сохраняется, чтобы действующие проверки исторического ядра и
сборочные якоря продолжали работать. Для каждого фрагмента результат дополнительно
сравнивается по AST с результатом официального компилятора TypeScript.
Ошибка типов, отключение строгой проверки или неподдерживаемое преобразование
останавливает сборку до замены файлов.

Автообновление сначала компилирует мод, затем вычисляет отпечаток входов.
Файлы `.ts`, общие объявления и `tsconfig.mod.json` участвуют в отпечатке.
Проверки Chromium и Firefox сохраняют подтверждение проверки типов; публикация
проверяет соответствие этого подтверждения текущим исходникам.
