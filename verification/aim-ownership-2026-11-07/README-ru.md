# Повторное подтверждение направления после управления мышью

7 ноября 2026 года. Дополнительная проверка после выпуска с ограничением фоновых отправок.

## Воспроизведённые ошибки

1. Цель выходит из FOV, и штатная мышь снова может отправлять направления. Мод сохраняет в кеше старый угол аимбота. Когда цель возвращается с тем же расчётным углом, удаление повторов ошибочно считает, что сервер уже смотрит туда. В воспроизведении расчёт равен 0°, мышь отправляет 90°, а затем передаётся только атака `[4]`. Результат до исправления: [before.json](before.json).
2. При включённом импортированном Jitter без цели источник продолжает вращение, но адаптер пропускает одновременно штатные повороты мыши. Два источника направления конкурируют, хотя фоновые команды аима уже ограничены по частоте.

## Исправление

Оба штатных обработчика спрашивают `controlsAimDirection` непосредственно перед своей отправкой. Если управление уступлено мыши, кеш последнего направления и допуск следующего фонового подтверждения сбрасываются. Когда аимбот снова получает цель, тот же числовой угол отправляется заново. Повторные чтения при уже сброшенном кеше ничего не добавляют в сеть.

Если импортированный Jitter включён вместе с аимботом, он сохраняет управление направлением и без цели. Выключение Jitter возвращает мыши управление. Независимый Jitter продолжает использовать свой прежний переключатель.

После исправления тот же сценарий передаёт `[6,0]`, затем `[4]`: [after.json](after.json). В отчёте Connection добавлен счётчик `aimTransport.nativeYields`. Формулы и извлечённое ядро Message15 не менялись; ограничение 50 мс, объединение направлений, целостность автоогня, обработка смерти и три изменения служебных подписей сохранены.

## Проверки

Добавлены проверки потери/возврата цели, повторного чтения признака управления, отключения, нового сокета, смерти и Jitter без цели. Браузерная проверка вызывает оба настоящих штатных обработчика поворота на подготовленных данных и подтверждает порядок направления перед штатной атакой. Пробы временно задают и восстанавливают штатные часы/кеш ввода только в стенде. Эти пробы не включаются в опубликованный JS.

Проверка обязательна в Chromium и Firefox перед публикацией через контракт `aim-pointer-ownership-resync`. Результаты выпуска, хеши и публикация находятся в `release-verification.json` и `publication.json` рядом с этим файлом.

Эти ошибки объясняют воспроизводимое расхождение расчётного и отправленного направления. Причинная связь с пользовательским серверным отключением не доказана. Живой двадцатиминутный сеанс без отключения этой проверкой не подтверждается.
