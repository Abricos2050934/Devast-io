# Повторная сверка ILM и опубликованной версии

8 ноября: HTML игры по-прежнему подключает `oBgZbNI48tDRbPbHHSZh.js`.
Свежая загрузка исходного JS: SHA256
`1a3807a85d8b36df3e97c51b4311c8a6c51a04b3ad65687d7e2366f1e1502c9b`.
До изменений опубликованная сборка `e439ccac...` использует этот же исходник.
Автоматический запуск GitHub 42499056311 (16:16 UTC) завершился успешно и
сообщил `unchanged`: новых исходников игры не было.

Четыре класса и исходный такт совпадают с сохранёнными декларациями из
25INVITES-ILM1.0.json. Функции выбора цели, resolve/wannaFire, истории,
округление, исходные 50 мс и пять меню-контролов не переписывались.

Обнаружены и удалены два добавления адаптера: отдельная папка ILM controls
и присвоение цвета линии из visualizeResolvingColor при старте/setSetting.
Оригинальный ILM не создаёт эти контролы и не использует поле цвета.
Настройки продолжают сохраняться; Space и Keyboard/AimbotKey остаются.
Исходный BulletSpeedCoefficient и resolverType не участвуют в формуле —
добавлять для них новый расчёт означало бы изменить ILM.

Новая обязательная браузерная проверка создаёт изолированное меню из
сохранённого исходного блока ILM в том же dat.GUI. Сравниваются порядок,
подписи, варианты, min/max/step всех пяти контролов и отсутствие дополнительных
настроек аима в других папках. Проверяется неизменность исходного цвета линии.
Она дополняет сравнение 2400 состояний, 18 сцен мыши и 72 вариантов нативного
серверного угла; публикация требует положительного результата в обоих браузерах.

Это совпадение ядра и проверенных путей интеграции. Штатный кодек, формат
пакетов новой игры, проверки невалидных целей и очистка сессий сохраняются.
Проверки не измеряют попадания на живом сервере. Для прямого сравнения с
другой сессией нужна именно та сборка, а не предположение о её содержимом.
