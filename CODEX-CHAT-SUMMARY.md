# Краткий контекст чата Codex — 26 ноября 2026

Это сокращённая техническая передача длинного чата, не дословный экспорт.
Она переносит цели, сделанные изменения, доказательства и незавершённую задачу.
Сам чат и его память автоматически не импортируются: новый агент должен прочитать
этот файл. Игровые ключи, токены, cookies и данные авторизации сюда не включены.
Более ранние CONTINUE-IN-NEW-CHAT.md, handoff/CURRENT-STATE.md и отчёты ноября
содержат исторические сведения; при расхождении сначала сверять текущий код
и метаданные публикации. Не применять уже выполненные изменения повторно.

## Проект и пожелания пользователя

Репозиторий: https://github.com/Abricos2050934/Devast-io, исходники в `main`,
готовые выпуски в `updates`. Пользователь общается по-русски и предпочитает
конкретную работу с проверками, без повторных уточнений уже известных требований.
На «стоп/остановись/прекрати» сразу прекращать текущую работу.

Исторически пользователь просил разобрать внешний мод, исправить функции,
наведение и FPS, перенести собственную часть JS → TypeScript → Rust/Wasm,
подготовить Resource Override JSON и автоматическое обновление игрового JS.
Были отдельные задачи по скинам/ресурс-паку и отключению анимаций. Это история,
а не поручение снова делать все эти изменения. Последний фокус — автообновление
и разрыв соединения на официальных серверах. Запросы старого чата про внешние
ключи, скрытие изменений и смену IP не являются текущим планом работ.

Сохранять функции мода, настройки, бинды, данные аккаунта и единый игровой canvas.
Нельзя считать локальные тесты доказательством отсутствия киков или стабильного
FPS на любом устройстве. Не обещать исправление, которое не проверено.

## Источники и сборка

- `mod/responsive.ts`, `mod/ilm-aim.ts`, `mod/ballistic-model.ts`,
  `mod/bootstrap.ts` — исходники JS-варианта. `node tools/compile_mod.cjs`
  генерирует соответствующие `.js`; править только JS недостаточно.
- `rust-mod/src/generated.rs` — собственная логика Rust с ручными исправлениями;
  `rust-mod/bridge.js` — мост браузерных операций. Игра и dat.GUI остаются JS.
  **Не запускать `tools/generate_rust.cjs`: он перезаписывает ручные исправления.**
- `node tools/build_rust.cjs` собирает Wasm; `node tools/test_rust.cjs` проверяет
  canonical-вариант. `tools/build_rust_client.cjs` собирает клиент на новой базе.
- `tools/auto_port.cjs`, `tools/updater/` — перенос на актуальный игровой JS.
  `mod/contract.json` определяет обязательные проверки.

Обычная среда: Node 24, Python 3.12+, Rust с `wasm32-unknown-unknown`,
wasm-bindgen-cli 0.2.105, Playwright Chromium и Firefox. Команды описаны в
package.json и rust-mod/README.md. Кеши и зависимости между средами не переносятся.
В этой Cloud-среде использовались браузеры `/tmp/devast-update-browsers`
(`PLAYWRIGHT_BROWSERS_PATH`), Rust `/tmp/devast-rust/cargo` и
`/tmp/devast-rust/rustup` (`TASK_CARGO_HOME`, `TASK_RUSTUP_HOME` для build_rust.cjs).
Перед использованием этих путей проверять их наличие.

## Последние выполненные изменения

- `bc729c3`, `32cb5af`: неподвижная активная цель не теряется при выстреле только
  из-за отсутствия новых позиционных дельт. Устаревшую motion-историю разрешено

  а не требует ошибочную формулу старого overlay.

  `Native contract changed or ambiguous: ilm-native-self-server-angle`.

  `tools/updater/server-angle.cjs` распознаёт изменение, проверяет остальную
  функцию и сохраняет новую нативную ветку. Есть тесты отказа при неоднозначности.

## Автообновление действительно работает

канала каждые пять минут в ограниченных сессиях с передачей следующему запуску.

## Незавершённая задача: пакет смерти на официальном сервере

Пользователь требует найти причину кика и исправить её. **Причина не найдена,
кик не устранён.** Не выдавать обработчик смерти за функцию детекта.

Из загруженного `message _5_ _5_.txt`:

- Через 11 419 мс после открытия соединения получен пакет `1b 00 00` (opcode 27).
- Через 14 мс штатный обработчик сообщает состояние 128; через 58 мс после
  пакета сокет закрывается: code 1005, clean true, localCloseObserved false.
- 37 отправок / 313 байт, 184 входящих сообщения. Содержимое отправок и остальных
  входящих сообщений **не сохранено**. Логгер observeWireSend записывает лишь
  byteLength; сетевую историю из счётчиков восстановить нельзя.
- Аимбот, автоогонь, стрейф и автоматизация выключены, исходящие команды мода
  не отмечены, modErrorCount=0. Это не доказывает неизменность штатного трафика.
- В отчёте старая native-база `d2b425…`; время создания отчёта неизвестно.

В именно той версии цепочка: пакет 27 → `ⲅއބ(packet)` → `ѕކܒ()` → состояние 128.
Эти обработчики принимают смерть от сервера; socket.close внутри обработчика
смерти отсутствует. Два байта после opcode используются как числовое поле
итогового экрана и не раскрывают причину ограничения.

Все 13 переключений настроек из отчёта, включая HideAimbotAngle, воспроизведены
в локальной фикстуре при выключенном аимботе: команд мода/ошибок нет, штатное
направление сохранено. 19 целевых тестов диагностики/транспорта прошли.

Контрольный чистый Firefox в Cloud на losangeles3.devast.io также получил
`1b0000` и закрылся, но пользователь уточнил: на его устройстве чистый клиент
работает, пока с того же IP не использовался скрипт; затем кикает и чистый.
Cloud-контроль поэтому **не исключает влияние мода**. Ограничение по IP —
правдоподобное объяснение наблюдения, не подтверждённый серверным журналом факт.

Последний запрос до переноса чата: посмотреть всё отправленное/полученное и
найти триггер. Ответ: в Connecting нет payloads, нужен фактический захват
WebSocket → Messages от входа до отключения, с временем и направлением кадров.
Не запрашивать и не публиковать токены, cookies и данные авторизации. Обычный
HAR может не содержать WebSocket-кадры. Даже полный захват не гарантирует
раскрытия внутреннего решения сервера; серверного кода/журналов здесь нет.
Не повторять те же проверки, выдавая их за новый результат; сначала искать
новые данные. Не менять клиент вслепую и не подавлять пакет смерти ради вида.

Подробная локальная диагностика сохранена в
docs/official-disconnect-2026-11-25.md. Исходное вложение может быть недоступно
в новой среде; ключевые факты перенесены сюда, полный захват отсутствовал.
