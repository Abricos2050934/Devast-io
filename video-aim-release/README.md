Экспериментальный аим с упреждением по задержке, созданный после разбора
пользовательского видео и скриншота. Подробности модели и её допущения находятся
в `docs/video-prediction-2026-11-23.md`.

Редактируемый код мода — TypeScript в `mod/*.ts`. Нативная игра в `native.js.gz`
остаётся JavaScript. Снимок взят с текущего на момент проверки адреса
`https://devast.io/js/JZnx28srLJnmqhN0xR90n6mj7QB.js`;
хеши исходника, профиля и проверенного результата записаны в `reference.json`.

```sh
npm ci --ignore-scripts
npm run typecheck
npm run build:video-aim
npm test
```

В отдельном архиве команда `npm run build` также собирает этот клиент.
Она проверяет строгие типы и соответствие результата уже проверенной сборке.
Для изменений формулы необходимо повторить функциональные и браузерные проверки
перед изменением контрольного хеша. Отчёты приложены в `reports/`.

Готовый файл импорта —
`artifacts/video-aim-hud-2026-11-23/Devast-io-Video-Aim-HUD.json`.
Он содержит полный собранный клиент. Файл загрузчика по публичной ссылке
в `resource-override/` здесь сохраняется как отдельный исходный компонент;
версия по публичной ссылке этим архивом не опубликована.

После импорта включить обычный AimBot либо AimbotSpear, затем
`Adaptive Aim → Расчёт перехвата` и
`Adaptive Aim → Video Prediction — эксперимент → Упреждение по пингу`.
Последний переключатель по умолчанию выключен.

Начальные параметры: резервный пинг 90 мс, окно до 125 свежих замеров,
2 шага уточнения, 1 мс дополнительной задержки и 20 мс предполагаемого ожидания
команды. Это собственная интерпретация скриншота, не расшифровка исходного кода
аима из ролика. Неподтверждённый автоматический пинг не имитируется: до получения
реальных RTT через интеграцию используются заданные 90 мс, источник обозначается
как `configured`. Интервал отправки пакетов не изменяется.

`npm test` в архиве проверяет типы и новый режим в локальных сценариях.
Отчёты полного набора тестов и Chromium/Firefox приложены отдельно.
Симуляция не подтверждает процент попаданий или отсутствие киков на живом сервере.
Публикация автообновления не выполнялась.

Статистика avgPing/currentPing/deltaPing/delay/lead выводится слева во время игры.
Флаг «Показать пинг слева» включён по умолчанию. Значение «задано» обозначает
резервный пинг, а прочерки — отсутствие замера. Режим аима отмечен отдельно.
